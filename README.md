```bash
npm install
npm run dev
```

## Build & deploy

Static Vite export. No Node at runtime.

```bash
npm test          # content guards + production build
npm run deploy    # wrangler pages deploy → project harsha-vardhan
```

Wrangler project name is `harsha-vardhan`. Never deploy this branch as `agentic-systems-studio`.
